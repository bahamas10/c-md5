md5 Implemented in C
====================

C implementation of the md5 checksum algorithm

Usage
----

```
cc md5.c -o md5
./md5 file.txt
./md5 < file.bin
echo 'hello' | ./md5
DEBUG=1 ./md5 file.txt
```
